# e-plantShopping

## Project Overview

e-plantShopping is a React and Redux web application for an online plant nursery. Users can browse plants by category, add plants to a shopping cart, update quantities, remove items, and view the total cart amount.

## Features

- Browse plants by category
- Add plants to the shopping cart
- Increase and decrease item quantity
- Remove items from the cart
- Calculate cart totals using Redux
- Continue shopping from the cart

## Technologies Used

- React
- Redux Toolkit
- JavaScript
- CSS
